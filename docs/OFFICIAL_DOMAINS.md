## Regra de segurança

- Não reconstruir fluxos validados para mudar domínio.
- Manter login, checkout, pagamentos, banco, Supabase e rotas funcionais.
- Alterações de domínio devem usar canonicalização/redirecionamento.
- Domínios antigos podem permanecer tecnicamente ativos durante transição, mas não devem ser apresentados como endereços oficiais.
- Novos links públicos devem usar somente os domínios oficiais acima.
